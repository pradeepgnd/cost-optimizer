## Pre-recording checklist

- [ ] **Fix `.env.example`.** Restore the line `METERLESS_RUNTIME_TOKEN=` (`app/adapters/live_nightshift.py` requires it). Set `ZETARIS_BINDINGS_FILE=data/localstack/bindings.json` to match the README.
- [ ] Fill in `.env` with the real Zetaris and Nightshift values. Keep the Planner (Lightning), Critic (Ultra), `METERLESS_NO_THINKING_ROLES=Planner,Critic`, `METERLESS_NO_THINKING_MODELS` listing both Nemotron routes, and `METERLESS_REQUEST_TIMEOUT_S=150`. **Never show `.env` on screen.**
- [ ] Docker is running Zetaris plus the `cost-optimizer-localstack` container on port 4566, with `LOCALSTACK_AUTH_TOKEN` set.
- [ ] Nightshift is running with the NVIDIA key in its Providers tab. Add the OpenRouter provider too, or only Ultra and Lightning will appear as candidates (about 111 routes with it, 74 without).
- [ ] The price-data bindings file exists (README Level 2) and the sidebar shows the green "Price data" line.
- [ ] Run `(cd app/engines/hmem/reference && npm ci)` (Node 20+).
- [ ] `python scripts/smoke_live.py` shows `SELECT 1`, `read_models`, `GET /v1/models` and the H-MEM self-test all PASS.
- [ ] Start the evidence publisher **and** Streamlit from the same terminal, with a fresh `SOURCE_INGEST_TOKEN` (README step 6). Otherwise the run ends `partial` and nothing is written back.
- [ ] Do a full rehearsal run of `example_3`. Confirm `complete`, "Writing evidence back (Zetaris)" in the trace, and at least one Critic flag to read out. If there's no flag, change the 2:00 line to "no flags on this run".
- [ ] Press **New run** before the take you record (a run ID only runs once). Restart Streamlit after any code change.
- [ ] Plan to speed up the 30–60 second run wait in editing. Keep the final cut between 1:00 and 4:00.
- [ ] Hide any terminal that shows tokens. The run should cost $0 on a free NVIDIA Developer Program key.
